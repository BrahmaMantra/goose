# BM_ 隐私与公开提交约定

公开仓库只包含通用代码、官方资料、接口定义和虚构示例。实际账号、应用状态、设备/模型配置、个人路径、授权资料和运行结果保存在仓库外。

| 内容 | 存放位置 | 公开规则 |
| --- | --- | --- |
| 实际配置与凭据 | 仓库外私有目录，文件权限 0600 | 不提交；示例仅使用空值或占位符 |
| 浏览器 Profile、Cookie、storage state | 仓库外专用目录，目录权限 0700 | 不共享，不复用个人日常浏览器目录 |
| 扫码二维码、截图、页面快照、下载 | 仓库外运行产物目录 | 不放进代码、PR、Issue 或公开附件 |
| 账号信息、作品数据、工具返回与日志 | 仓库外私有运行目录 | 验证时仅在本地查看，公开报告只给出脱敏结论 |
| 模型标签、硬件与本机路径 | 本地环境或私有配置 | 公开命令使用 `BM_LOCAL_MODEL` 和通用路径 |

目录权限与 Git 忽略规则不是加密措施，也不能阻止用户显式强制上传。实际配置不混入 MCP 工具描述或公开测试证据。后续接入模型时，只传递任务所需的最少字段；凭据不进入模型上下文。

根 `.gitignore` 忽略 `BM_private/`、`BM_local/`、`BM_runtime/`，以及定制目录内的私有运行目录、浏览器 Profile、会话、下载、产物、虚拟环境、`.env` 与 `*.local.*` 文件。优先在仓库外存储这些文件；忽略规则作为防误提交的补充。

提交前运行：

```bash
python3 BM_custom/BM_douyin/BM_scripts/BM_privacy_check.py
```

检查器审查暂存区中的定制改动，拒绝被强制暂存的忽略文件，检测常见个人主目录路径与凭据字面量。它只能辅助审查，不保证识别全部隐私；提交前仍需检查新增内容和附件。检查输出不打印被匹配的内容。

PR 标题、描述、评论、提交信息和附件同样公开可见。不得把用户的账号或入驻状态、环境检查原文、真实响应和个人会话过程写到这些地方。

`.gitignore` 不会移除已跟踪文件，也不会清理已推送的 Git 历史。发生公开暴露后，应先清理当前文件与公开描述，明确历史仍然存在；历史改写与强制推送需要单独授权。即使改写分支，GitHub 的旧提交链接、PR 引用、缓存以及其他人的克隆仍可能保留旧内容，完整处理流程参考 [GitHub 官方说明](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)。
