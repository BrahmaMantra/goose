# 抖音只读检查

1. 调用 `BM_check_account`。只有状态为 `authenticated` 才继续；未登录、未配置、不支持页面或错误时说明限制并停止。
2. 用户需要作品信息时调用 `BM_list_works`，`BM_limit` 为 1～3 的整数，默认 3。使用 Goose 实际提供的 Plugin 工具命名空间。
3. 根据工具返回说明执行状态、读取数量和范围。将 `BM_complete=false` 解释为当前已加载列表的部分记录；`BM_more_loaded` 只说明当前 DOM 存在超过读取上限的条目。
4. 使用中文简短答复，区分已执行、未执行和执行失败。不要把先前保存的结果当作本次读取结果。

工具会在本地读取真实账号和作品字段，但模型仅获得脱敏摘要。账号字段为昵称和抖音号；作品字段为标题/描述文字、展示时间、状态标签和截断标记。播放量、点赞等统计指标未读取，不推测字段值或计数。

需要查看真实字段时，提示用户在本地执行 `BM_douyin results account` 或 `BM_douyin results works`。不要自行读取私有文件，也不要请求上传账号信息、登录资料或日志。

不要执行发布、编辑、删除、评论、翻页、导出、任意 Shell 或其他 Skill。遇到权限拒绝时停止，不尝试绕过。Skill 提供操作知识，实际授权与参数限制由 Hook 和 MCP 服务校验。
